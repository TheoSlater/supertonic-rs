## Default Permission

Default permissions for the Supertonic TTS plugin

#### This default permission set includes the following:

- `allow-synthesize`
- `allow-synthesize-stream`
- `allow-load-model`
- `allow-list-voices`
- `allow-select-voice`
- `allow-get-status`
